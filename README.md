# Uitnodiging en programma

## Website starten

1. Clone de repository van GitHub.
2. Plaats de map in `htdocs`.
3. Start Apache via XAMPP.
4. Open `http://localhost/naam-van-de-map/` in je browser.

## Git-opdracht

* **Stage:** bestanden klaarzetten voor een commit met `git add .`.
* **Commit:** wijzigingen opslaan met `git commit -m "Beschrijving"`.
* **Push:** commits uploaden naar GitHub met `git push`.
* **Clone:** een kopie van de repository maken met `git clone`.
* **Pull:** nieuwe wijzigingen ophalen met `git pull`.

## Verbetering testen

Clone de repository in een aparte map, maak een kleine verbetering, commit en push deze. Haal de wijziging vervolgens met `git pull` op in de andere map.
